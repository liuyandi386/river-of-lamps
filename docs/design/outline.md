# 灯河 / River of Lamps：设计大纲（v0.2）

> 依据 `概要.txt`，并结合本次拍板结果。规则细节见 `rules/element_rules.md`，决策记录见 `design/decisions.md`。

## 1. 定位

- 中文名：**灯河**
- 英文名：**River of Lamps**
- 副标题：即时逻辑布线解谜
- 一句话：**在网格上布线，让灯的信号汇成一条正确的河。**
- 单局：2–5 分钟；可暂停；失败立即重试。

## 2. 世界观与视觉

概要**没有叙事世界观**（无角色、剧情、阵营）。可用的是名字与视觉母题：

- 信号 = 灯光：高电平暖黄，低电平暗蓝；
- 导线 = 灯槽：信号经过时逐格亮起；
- 毛刺/竞争 = 红灯急促闪烁，像河道乱流；
- 目标端口 = 河口灯塔；
- 干扰源 = 河道暗流。

**结论**：按“无叙事、纯机制 + 氛围”处理，不补剧情。

## 3. 核心玩法

1. **空间布线**：在网格上放元件、画灯槽；逻辑由空间布局表达，不写代码。
2. **物理延迟**：灯槽每格 1 拍；正确 = 值正确 + 到达拍正确。
3. **目标序列**：目标端口按拍比对期望；失败高亮第一错拍。
4. **拍数预算**：不是现实倒计时；暂停不消耗拍。
5. **失败可视化**：颜色流动 + 目标/实际波形 + 首错反馈。
6. **快速迭代**：可暂停、可重试、可撤销。
7. **复杂度阶梯**：三批元件，每关只引入一个新概念。

## 4. 游戏循环

```
读题 → 布线 ⇄ 运行/暂停 → 失败定位 → 改布局 → 再运行 → 通过 → 下一关
```

- 读题：目标序列条 + 拍号。
- 布线：逐格画灯槽；走门输入/输出。
- 运行：逐拍播放；暂停可编辑。
- 迭代：首错拍 + 波形红色标记。
- 通过：解锁下一关。

## 5. 系统模块

| 模块 | 职责 |
|---|---|
| 网格/元件图 | 占位、端口、有向连接、灯槽方向 |
| 元件规则 | 源/门/目标/灯槽；后续延迟/脉冲/触发/计数 |
| 按拍模拟 | 每拍推进、0 延迟门、1 拍灯槽、目标比对 |
| 画布 | 网格、灯槽、元件、信号颜色、错误高亮 |
| 波形 | 目标/实际/拍号/首错 |
| 关卡数据 | JSON + 参考解 + 索引 |
| 运行控制 | 编辑/运行/暂停/失败/通过 |
| 存档 | 解锁进度（`user://progress.json`） |
| 后续 | 关卡编辑器、验证器、音频、手柄 |

## 6. 内容结构

### 当前 MVP

| 关 | 名字 | 教什么 | 参考完成拍（3 星） |
|---|---|---|---|
| 1 | 细流 | 灯槽连通 + 每格 1 拍（唯一最短直线） | 6 |
| 2 | 倒影 | 非门：源脉冲翻成先灭后亮，不能靠直连通关 | 3 |
| 3 | 第一盏灯 | 非门翻转脉冲 | 4 |
| 4 | 汇流 | 与门：两路同拍 | 4 |
| 5 | 分岔 | 或门：两路差 2 拍 | 6 |

> 第 1、2 关的 `teach` 文案、参考解和 `star_thresholds` 见 `data/levels/level_01.json`、`level_02.json`；3 星阈值贴着参考解，2 星适度放宽，1 星只需在窗口内通关。

### 规划

| 段 | 关卡 | 元件 | 目标 | 新概念 |
|---|---|---|---|---|
| 教学 | 1–5 | 第一批 | 1–2 拍 | 源/灯槽/与/或/非/目标 |
| 时序 | 6–15 | 第二批 | 3–5 拍 | 延迟/脉冲/触发器/计数器 |
| 干扰 | 16–30 | 第三批 | 3–5+ | 干扰/衰减/中继/竞争/屏蔽 |
| 后期 | 30+ | 全 | 多端口 | 多目标/多源/受限网格/上限 |

关卡命名沿“细流 → 倒影 → 第一盏灯 → 汇流/分岔/浅滩 → 暗涌/乱流/逆流 → 灯河/入海口”。

## 7. 难度原则

- 第 1 关必须 5 分钟内通过；目标 1–2 分钟。
- 每关只引入一个新概念，并与旧概念组合。
- 先保证“看得见”（颜色/波形），再谈难度。
- 后期难度来自：序列变长、路径重汇聚、干扰、网格受限、元件上限。
- MVP 不做星级/评分；结算只显示拍数与元件数。

## 8. 已拍板

- 混合延迟：门 0 拍，灯槽 1 拍；有环迭代上限 16。
- 做非门。
- 5 关：3 教学 + 2 组合（可浮动）。
- 限时 = 拍数预算。
- 中继元件 + 确定性衰减（第二批实现）。
- `max_components` 只数功能元件，灯槽不算。
- Godot 4 + GDScript。
- 英文名 River of Lamps。
- 逐格画灯槽。
- 时序参数全部 JSON 化（第二批实现）。

## 9. 当前边界

已实现：5 关、第一批元件、按拍模拟、目标波形、首错高亮、进度存档、撤销。

未实现：第二批/第三批、编辑器、验证 CLI、音频、手柄、旋转、多目标、真正的逐事件毛刺。
