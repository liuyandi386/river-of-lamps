游戏设计概要：即时逻辑门解谜
1. 一句话定位
在网格上放置并连接逻辑元件，让信号在限定时间内按正确时序到达目标端口；信号有物理延迟，后期加入干扰与竞争冒险，核心是“布线”而非“编程”。

2. 目标玩家与体验
喜欢“元件组合产生涌现行为”的玩家，但想要短局、即时的解谜体验。

单局 2–5 分钟，可暂停调整，失败可立即重试。

快感来源：看见信号在网格上流动、定位毛刺、调整布局后一次通过。

3. 核心循环
读题：目标端口显示需要的脉冲序列（如“高-低-高，间隔 2 拍”）。

布线：在网格上放置元件、连线，信号实时流动，可随时暂停调整。

验证：点“运行”，信号跑一遍，失败显示哪一拍、哪个节点出错。

迭代：改布局、加延迟、换元件，直到通过。

4. 元件系统（分三批解锁）
第一批：教学
信号源（持续高/低、单脉冲）

导线（1 格传播延迟）

与门、或门、非门

目标端口（显示收到的序列，标记对错）

第二批：时序
延迟元件（可调 1–5 拍）

脉冲发生器（周期可调）

边沿触发器（上升沿/下降沿翻转）

计数器（每 N 个脉冲输出一次）

第三批：干扰与竞争
干扰源（周期性翻转邻近导线信号）

信号衰减（长导线信号变弱，需中继）

竞争冒险（两条路径延迟不同，输出可能毛刺；教学重点）

屏蔽线（抗干扰，占双格）

5. 模拟规则
离散时间步（每拍推进一次），所有元件按拍更新。

导线每格 1 拍延迟；元件有自身延迟属性。

同一拍内节点多次翻转记录为“竞争”，可视化为红色闪烁。

目标端口按拍比对期望序列，失败时高亮第一个错误拍。

6. 难度曲线
第 1–5 关：单一元件教学，目标序列 1–2 拍，无干扰。

第 6–15 关：组合门电路，引入延迟和脉冲，目标序列 3–5 拍。

第 16–30 关：引入干扰和竞争冒险，要求时序对齐而非只堆逻辑。

后期：多目标端口、多信号源、网格受限、元件数量上限。

原则：每关只引入一个新概念，且新概念必须与旧概念组合出题。

7. 避免变成编程游戏的设计约束
不做文本输入，全部拖拽放置，逻辑靠空间布局表达。

不做变量和循环抽象，用计数器、脉冲发生器等物理元件替代。

强调空间维度：导线长度、元件相邻、干扰范围。

失败反馈可视化：信号颜色流动 + 波形面板，让玩家“看见”毛刺和错位。

8. 技术架构
Python 层（工具与内容）
关卡编辑器：网格放置、元件属性、目标序列配置，导出 JSON。

关卡验证器：自动跑参考解，确保可解。

元件规则表：输入输出逻辑用 Python 描述，便于调平衡。

C++ 层（运行时）
网格与元件图：节点 + 有向边，边带延迟权重。

信号模拟：离散时间步推进，支持毛刺检测。

渲染：网格、导线、信号颜色流动、波形面板。

干扰系统：周期性事件修改邻近节点信号。

关卡 JSON 结构（草案）
json
{
  "id": "level_01",
  "grid": {"w": 8, "h": 8},
  "preset": [{"type": "source", "pos": [0,0], "mode": "high"}],
  "available": ["wire", "and", "or", "not", "target"],
  "target_sequence": [1, 0, 1],
  "interference": [],
  "max_components": 10,
  "hint": "把源连到目标，注意导线延迟"
}
9. MVP 范围
网格 8×8。

元件 5 种：信号源、导线、与门、或门、目标端口。

离散时间步模拟，无干扰。

5 关：3 关教学 + 2 关组合。

信号用颜色显示，失败高亮错误拍。

技术栈：Python + pygame 先验证手感，模拟层设计为可迁移到 C++。

10. 验证目标（MVP 阶段）
玩家能否在 1 分钟内理解“信号按拍传播”。

失败反馈能否让玩家自己定位错误。

单局时长是否落在 2–5 分钟。

11. 已知风险
学习曲线：第一关必须 5 分钟内通过，否则流失。

竞争冒险可读性：毛刺需明显可视化（红色闪烁 + 波形标记）。

内容量：靠关卡量，编辑器要做扎实，后期可考虑创意工坊。

定位清晰：不加经营元素，明确短局解谜。

名字与定位
中文名：灯河
英文名：River of Lamps / Lampflow（二选一，Lampflow 更短、更适合商店）
副标题：即时逻辑布线解谜
一句话：在网格上布线，让灯的信号汇成一条正确的河。

名字如何落到美术与反馈上
信号可视化：高电平用暖黄光，低电平用暗蓝，信号流动像灯在网格上“点亮—熄灭—再点亮”，形成流动感。

导线：不是线条，而是“灯槽”，信号经过时逐格亮起。

毛刺/竞争：同一拍内多次翻转显示为红灯急促闪烁，像河道里的一处乱流。

目标端口：像河口的灯塔，按拍接收灯信号，对错用灯光颜色反馈。

干扰源：像河道里的暗流，周期性把邻近灯槽的信号打乱。

关卡命名可以贴“河”的意象
教学关：细流、源头、第一盏灯

组合关：汇流、分岔、浅滩

干扰关：暗涌、乱流、逆流

后期关：灯河、入海口

这样关卡列表本身就是一条“从细流到灯河”的进程，和名字呼应。

商店/宣传语草案
“布线，点灯，让信号汇流。”

“每一拍都算数。”

“一条由灯组成的河，等你接通。”
